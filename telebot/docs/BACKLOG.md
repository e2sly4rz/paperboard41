# Backlog

## Отложено сознательно

### Результаты опроса после закрытия
Сейчас `poll_results` работает только для активного опроса. После закрытия — «Активного опроса нет». Нужно: `get_last_poll_for_night` без фильтра по статусу, разделение флагов в `host_night_card_with_poll`, показ «Статус: закрыт» в результатах.

### Защита от пересечения игр по времени
Игрок может записаться на Catan (18:00–20:00) и Codenames (19:00–20:30). Нужно: проверка `time_start < end_B AND start_B < time_end` в `register_for_session`, пометка `⚠️` в списке игр.

### Уведомление автору игры при отмене записи
Сейчас при `cancel_registration` никто не уведомляется. Нужно: после удаления записи отправить владельцу игры (`games.owner_user_id`) сообщение.

### Автозапись по уровням
Колонки `registration_opens_at`, `registration_min_level`, `registration_approved` есть, но логика не включена. Нужно: при записи проверять уровень пользователя и время открытия.
