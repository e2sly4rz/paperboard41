# Руководство игрока

## Первый запуск

Откройте бота, отправьте `/start`. Если вы новый пользователь — бот покажет «Заявка отправлена» и ваш ID. Организатор одобрит доступ, и вы получите уведомление.

После одобрения — снова `/start`. Появится главное меню:
- 📅 Расписание
- 🎲 Мои записи

## Роли

- **Пассажир** — базовый уровень. Может записываться на открытые игры.
- **Проводник** — доступ к играм с 🔒.
- **Организатор (хост)** — создаёт игротеки, управляет играми.

Уровень выдаёт админ командой `/grant <id> provodnik` (или `host`).

## Просмотр расписания

«📅 Расписание» → список ближайших игротек. Выберите дату → список игр кнопками:
🟢 18:00 · Catan · 2/4
🟡 19:00 · Codenames · 3/6
⛔ 20:00 · Ticket to Ride · 5/5
Маркер:
- 🟢 0–25% заполнено
- 🟡 26–50%
- 🟠 51–75%
- 🔴 76–99%
- ⛔ 100% (мест нет)

🔒 рядом с названием — только для Проводников.

## Запись на игру

Нажмите на игру → откроется карточка с временем, местом, свободными местами. Если есть места — кнопка «✅ Записаться».

Если запись успешна — «Вы записаны». Если нет — всплывающее сообщение с причиной:
- «Свободных мест больше нет»
- «Вы уже записаны»
- «Только для подписчиков Проводник»

После записи кнопка «⬅️ Назад» возвращает в список игр той же игротеки.

## Мои записи

«🎲 Мои записи» → список ваших будущих игр. Нажатие на запись — отмена.

## Опрос о времени

Если хост создал опрос — в карточке игротеки появляется кнопка «⏰ Указать удобное время».

1. Выберите час, с которого вы готовы начать.
2. Выберите час, до которого готовы играть.
3. Бот сохранит ответ.

Повторный ответ перезаписывает предыдущий.

## Напоминания

Бот присылает напоминания автоматически:
- за ~24 часа до первой игры дня — «📅 Напоминание: игра завтра»
- за ~1 час до первой игры дня — «⏰ Напоминание: игра через час»

В напоминании — список всех игр, на которые вы записаны в этот день.

## Уведомления

Вы получаете уведомления, если:
- вашу заявку одобрили;
- игру, на которую вы записаны, отменили;
- хост создал опрос о времени.
