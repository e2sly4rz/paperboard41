# Changelog

## [Текущая версия]

### Добавлено
- Роли: `host`, `provodnik`, `passenger` с `CHECK` в схеме.
- Единое соединение `Database` (`db.conn`) вместо `aiosqlite.connect` в каждом запросе.
- Модуль `notifications.py` с `_safe_send` и тремя уведомлениями об удалении игры.
- Опрос о времени: создание, ответ, результаты, закрытие.
- Уведомление записавшихся о создании опроса.
- Команда `/users` — список пользователей по уровням.
- `created_by_user_id` в `game_sessions` — автор игры.
- Удаление своей игры в чужой игротеке.
- `host_night_card_with_poll` с флагами `has_active_poll` / `has_any_poll`.
- Маркеры заполненности по проценту: 🟢/🟡/🟠/🔴/⛔.
- Fallback локали в календаре.
- Возврат после записи в ту же игротеку.
- Возврат в карточку после создания игротеки.

### Изменено
- `handlers/host.py` разбит на модули (`menu`, `create`, `edit`, `sessions`, `delete`, `poll`, `_helpers`).
- `utils.py` с `fmt_date`, `is_admin`, `is_host`, `is_host_or_admin`.
- Время и длительность — кнопки с шагом 1 час.
- Количество мест — автозаполнение из `max_players`.
- Меню организатора — сразу список игротек без промежуточного экрана.
- Напоминания группируются по дням (одно сообщение на день).

### Исправлено
- `locale.Error` в systemd — добавлена переменная окружения.
- `TypeError: has_poll` — заменено на `has_active_poll` / `has_any_poll`.
- Дубликаты хендлеров при рефакторинге.
- Неиспользуемые импорты.

### Отложено
- Результаты опроса после закрытия.
- Защита от пересечения игр по времени.
- Уведомление автору игры при отмене записи игроком.
- Автоматическое открытие записи по уровням (колонки есть, логика не включена).
