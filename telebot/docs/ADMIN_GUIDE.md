# Руководство администратора и организатора

## Команды администратора

| Команда | Что делает |
|---|---|
| `/pending` | Список заявок на доступ |
| `/approve <id>` | Одобрить пользователя |
| `/revoke <id>` | Отозвать доступ |
| `/grant <id> host` | Сделать организатором |
| `/grant <id> provodnik` | Выдать «Проводника» |
| `/grant <id> passenger` | Снять привилегии |
| `/users` | Список всех пользователей с уровнями |
| `/help` | Справка по командам |
| `/id` | Свой Telegram ID |

## Создание игротеки (хост)

1. «🎩 Меню организатора» → «➕ Создать игротеку».
2. Выберите дату в календаре.
3. Введите место.
4. Найдите игру (поиск по названию, минимум 2 символа).
5. Выберите время начала (кнопки 10:00–23:00 с шагом 1 час).
6. Выберите длительность (1–6 часов, галочки у рекомендуемых).
7. Выберите количество мест (автозаполнение из `max_players`).
8. «➕ Добавить ещё игру» или «✅ Завершить создание».

После завершения открывается карточка созданной игротеки.

## Карточка игротеки

В меню организатора видны:
- **🎩** — ваши игротеки
- **👀** — игротеки других хостов

Карточка содержит:
- дату, место, счётчики;
- список всех игр с временем и «занято X из Y»;
- под каждой игрой — имена записавшихся (или «никто не записан»);
- кнопки управления.

## Кнопки управления

| Кнопка | Что делает |
|---|---|
| ➕ Добавить игру | Поиск и добавление игры |
| 🎲 Управление играми | Список игр, удаление своих |
| 📊 Создать опрос / Результаты / Закрыть | Опрос о времени |
| 📅 Изменить дату | Редактирование даты |
| 📍 Изменить место | Редактирование места |
| 🗑 Удалить игротеку | Удаление с уведомлениями |

Кнопки редактирования видны только владельцу и админу. Чужой хост видит «➕ Добавить игру», «🎲 Управление играми», «⬅️ К списку».

## Добавление игры в чужую игротеку

1. «🎩 Меню организатора» → выберите игротеку с 👀.
2. «➕ Добавить игру» → поиск → время → длительность → места.
3. Игра добавлена. В «🎲 Управление играми» у вас будет 🗑 только на ваших играх, `•` на чужих.

## Удаление игры

Нажатие 🗑 → предупреждение с числом записавшихся → подтверждение.

При удалении:
- игрокам приходит «❌ Игра отменена»;
- владельцу игры (если есть) — «🔔 Ваша игра удалена»;
- владельцу игротеки (если удаляет не он) — «🔔 Из вашей игротеки удалена игра».

Инициатор уведомлений не получает.

## Опрос о времени

1. В карточке игротеки → «📊 Создать опрос о времени».
2. Записанные игроки получают уведомление.
3. Игроки отвечают в карточке игротеки в «📅 Расписание».
4. Хост нажимает «📊 Результаты опроса» → видит гистограмму по часам и список ответов.
5. «🔒 Закрыть опрос» — ответы больше не принимаются.

После закрытия кнопки «Результаты» и «Создать новый опрос» остаются.

## Что видит админ

Админ видит все игротеки с 👀 (кроме своих, если создавал), может редактировать и удалять любую. В карточке — пометка «(админ: игротека другого хоста)».

## Владелец игры
